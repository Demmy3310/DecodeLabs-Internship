# DecodeLabs_Internship- PASSWORD STRENGTH CHECKER.
🔐 Password Strength Checker

A beginner Python project that checks the strength of a password using basic security requirements.

📌 About the Project

I built this project as part of my cybersecurity learning journey to understand how Python can be applied to a simple cybersecurity problem.

The program evaluates a password based on:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Based on these checks, the password is classified as Weak, Medium, or Strong.

🛠️ Technologies Used

- Python 3
- Visual Studio Code

⚙️ How It Works

The program asks the user to enter a password and then checks it against several conditions.

User enters password
        ↓
Check password length
        ↓
Check for uppercase letters
        ↓
Check for lowercase letters
        ↓
Check for numbers
        ↓
Check for special characters
        ↓
Evaluate the conditions
        ↓
Display password strength
